# Etapa 00 — Base da Memória

## Objetivo

Criar a estrutura de memória do projeto conforme a metodologia de trabalho.

## O que foi feito

- Criado o diretório `docs/memoria/`.
- Criado `docs/memoria/INDEX.md` com:
  - contexto do projeto (Identity & Tenants);
  - tabela `Histórico de Etapas` (com a etapa 00 registrada);
  - seção de decisões estruturantes ainda pendentes;
  - instruções de como registrar novas etapas.

## Decisões técnicas e por quê

- **Diretório `docs/memoria/`**: centraliza toda a memória do projeto em um único
  lugar navegável, conforme orientado na metodologia.
- **`INDEX.md` como porta de entrada**: obriga a leitura do contexto acumulado
  antes de cada etapa, evitando decisões conflitantes.
- **Nomenclatura `etapa-XX-<nome>.md`**: numeração sequencial que preserva a
  ordem cronológica e facilita consultas.
